## Правила процесса (обязательны для любого пункта)

- Всё — через PR; прямых пушей в `main` нет.
- `npm run typecheck` и тесты перед коммитом; вывод не обрезать так, чтобы не видно было строку `Test Files`.
- Миграции накатывает **только бот** (`deploy.sh`: bot → dashboard → home-groups); миграции нумеруются с `073`, идемпотентные, с тестом на их SQL (паттерн `016`).
- Новая обязательная env-переменная — в серверный `.env` **до** мержа.
- Удаление полей — только мягкое (скрыть в UI, колонки не дропать), пока не подтверждено, что данные не нужны ни выгрузкам, ни помощнику.
