# Переход на новый интерфейс «Домашние группы» и отключение старого дашборда

Для владельца сервиса и руководителя координаторов. Простыми словами, без лишних подробностей.

## Что перенесено

Всё, чем служители пользовались в старом дашборде, теперь есть в новом, кроме двух вещей (см. ниже).

| Было в старом дашборде | Где теперь |
| --- | --- |
| Реестр групп, правка, удаление | «Справочник» → Группы (ведущий и соведущий выбираются из «Людей», их телефоны — из карточек людей) |
| Заявки, статусы, ответственный | «Заявки»: подбор и утверждение, «Закрыть заявку…» (обработано или аннулировать с причиной), «Вернуть в работу», «В работе у», итог звонка, правка данных |
| Заявки «готов открыть», вопросы, «уже состою» | «Заявки» → переключатель «Другие обращения» |
| Регистрация участника, QR, печатная карточка | «+ Создать» → «Участник (регистрация)» и «Справочник» → Люди |
| Страница для волонтёров `/registration` | то же имя: `ВАШ-АДРЕС/registration` — только форма, без списков |
| Добавить заявку, группу, участника (координатора) | «+ Создать» |
| 40 дней: статистика, сетка материалов, рассылки | «Команда» → раздел «Кампания «40 дней»» |
| Участники CSV | «Команда» → «Выгрузка» (только полный вход) |
| Удаление регистрации | «Справочник» → Люди → «Удалить регистрацию» (только полный вход) |

Добавилось сверх старого: подбор группы, «Сегодня», «Команда» (нагрузка и сроки), массовые действия, «Мои виды»,
личные входы, журнал действий.

**Сознательно не перенесено:** раздел «Аналитика» (четыре графика) и цель «150 групп» на плитке.

## Перед отключением старого дашборда

1. В `.env` на сервере задан `HG_PUBLIC_URL` — адрес нового интерфейса, как его открывают люди, например
   `http://5.23.48.25:8092`. По нему бот ведёт служителей в новый интерфейс. Без него ссылки в боте останутся на старый.
2. Новый интерфейс открывается и принимает входы.
3. Пройдите 10 минут по сценариям: зарегистрируйте тестового участника (откройте `/registration`, получите QR);
   откройте его заявку в «Заявках», позвоните-отметьте, закройте и верните в работу; откройте «Команда» и «Кампанию»;
   удалите тестового участника.
4. Вопросы про время и адрес включены, как вы хотите (см. ниже).

## Как отключить

На сервере в файле `.env` одна строка:

```
LEGACY_DASHBOARD=off
```

и выкладка (она сама остановит старый дашборд и больше не будет его поднимать). Если выкладывать нечего, достаточно:

```
docker compose --profile legacy stop dashboard
```

Бот, база, бэкапы и новый интерфейс этого не замечают. Данные ничего не теряют: у обоих интерфейсов одна база.

**Как вернуть:** убрать строку `LEGACY_DASHBOARD=off` (или поставить `on`) и выложить заново, либо
`docker compose --profile legacy up -d dashboard`.

Побочный плюс: старый дашборд пускал по общим паролям, а личные входы работают только в новом. Пока он включён,
доступ полностью личными входами закрыть нельзя; после отключения можно.

## Как отправить через бот два дополнительных вопроса (для Давида)

Два вопроса: «Когда удобно?» и «Где живёте?». Их получают те, кто хочет в группу, готов открыть её или дать дом.

**Новым людям** они задаются сами, прямо в общей анкете, сразу после возраста. Нужно только их включить:

1. В новом интерфейсе: «Настройки» → «Бот: новые вопросы анкеты» → выберите «Всем» → «Сохранить». Бот подхватит
   настройку в течение минуты. Для пробы сначала можно выбрать «Только этим людям» и вписать свой номер (его показывает
   команда `/whoami` в боте).
2. Проверьте на себе: пройдите анкету в боте до вопроса про возраст — следом должны прийти два вопроса.

**Тем, кто уже зарегистрирован,** вопросы нужно дослать. Бот-служителем быть не обязательно, это можно сделать
из интерфейса (полный вход):

1. «Настройки» → «Бот: новые вопросы анкеты». Сначала выберите, кому задавать («Всем» или «Только этим людям»), и
   нажмите «Сохранить»: приглашения уходят по **сохранённой** настройке.
2. Ниже в блоке «Дослать вопросы…» выберите, кому отправить: ищущим группу или ведущим групп. Видно, сколько человек получит приглашение, и тексты, которые они увидят.
3. «Отправить доп. вопросы» → подтвердите число. Каждый получит приглашение один раз; ответы сами лягут в его заявку.

Получателем становится только тот, кто уже зарегистрирован в боте с заявкой «хочу в группу» или «готов открыть» и
ещё не отвечал. Если пробуете на себе, а в списке вас нет, пройдите анкету в боте: вопросы придут прямо в ней.

Из бота то же делает служитель кнопкой «📝 Дослать вопросы» (ваш номер в списке администраторов; проверка:
`/whoami`). Правила те же.

Ответы видны в «Заявках» в карточке: «Удобные день и время» и «Улица, дом».

Если «Настройки» вам недоступны (раздел только для полного входа), попросите владельца сервиса: он выберет режим «Всем» и сам отправит приглашения.
