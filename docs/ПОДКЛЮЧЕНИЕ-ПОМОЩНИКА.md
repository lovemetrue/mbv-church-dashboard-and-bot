# Подключение помощника (DeepSeek)

Для владельца сервиса (Димы). Три шага, около пяти минут.

## Что это

Помощник — языковая модель DeepSeek. Она читает запись человека (возрастная категория, место, удобное время),
определяет район и время там, где скрипт не понял, и подсказывает вопросы для разговора. **Группу выбирает не она**, а
обычный расчёт сервиса. Кнопка в «Заявках»: «Попросить помощника разобрать заявки».

К сервису DeepSeek уходит только: возрастная категория, место и удобное время в записи человека. Имена, телефоны,
почты и адреса не отправляются; номера телефонов и почты в тексте вырезаются. Сервис DeepSeek работает за пределами
России, поэтому перед включением согласуйте это с ответственным за персональные данные.

## Шаги

1. **Ключ.** В кабинете DeepSeek создайте ключ (API key) и поставьте месячный лимит расходов.
2. **Сервер.** В файле `.env` на сервере (рядом с токенами ботов) добавьте строку и сохраните файл:

   ```
   DEEPSEEK_API_KEY=ключ-из-кабинета
   ```

   Необязательно: `DEEPSEEK_MODEL=deepseek-chat` (по умолчанию именно она).
3. **Перезапуск.** На сервере из папки проекта: `docker compose up -d home-groups`. Бот перезапускать не нужно.

Потом руководитель в интерфейсе: «Настройки» → «Помощник» → «Помощник включён». По умолчанию он выключен.

## Важно про ключ

- Ключ живёт **только в `.env` на сервере**. В репозиторий (GitHub), чаты, письма и скриншоты его не кладут.
- Если ключ попал куда-то лишний раз, отзовите его в кабинете DeepSeek и выпустите новый.
- Вводить ключ через сайт нельзя нарочно: сайт пока открывается по `http://`, без шифрования, и ключ при вводе
  мог бы перехватить посторонний. Когда появится домен с `https`, можно вернуться к этому вопросу.
- Поменять ключ: поменять строку в `.env` и снова выполнить `docker compose up -d home-groups`.
